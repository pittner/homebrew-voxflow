# homebrew-voxflow

Homebrew tap for VoxFlow Pro, a free push-to-talk dictation app for macOS 14 and later (Apple Silicon and Intel). The audio is transcribed on the Mac with WhisperKit. The app downloads its Whisper model on first launch, after that it works offline.

```sh
brew install --cask pittner/voxflow/voxflow-pro
```

The DMG is notarized by Apple. Product page: https://bemooore.com/voxflow/mac/?utm_source=homebrew_tap&utm_medium=readme&utm_campaign=brew_tap
